# specs — DevDigest (cross-cutting)

Cross-package feature/contract specifications (course lesson L0x work that spans
more than one package). Add `YYYY-MM-DD-feature.md` here (Spec ID
`SPEC-YYYY-MM-DD-feature`) and link it from the root `CLAUDE.md` under "Read
when". Older `NN-feature.md` files predate this standard — do not continue the
numbering. Package-local specs live in `<package>/specs/`.
